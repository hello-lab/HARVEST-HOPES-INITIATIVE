# 🌾 Harvest Hopes Initiative — Confluence '24

A heart-driven, community-centered website built for the **Harvest Hopes Initiative** — an NGO dedicated to combating hunger and feeding those in need. Developed as part of the **Confluence 24 Hackathon**, this website provides a simple, accessible platform for people to learn about the cause, donate food or funds, and join volunteer efforts.

---

## 💚 About the Initiative

**Harvest Hopes** is a not-for-profit movement aimed at:
- Reducing food wastage
- Organizing food drives and community kitchens
- Delivering meals to underprivileged families and individuals
- Raising awareness about food insecurity

This website acts as the digital face of the initiative — connecting donors, volunteers, and supporters.

---

## ✨ Features

- Clean, responsive website built with **pure HTML, CSS, and JavaScript**
- Information about the NGO's mission and ongoing campaigns
- Easy-to-use **donation pledge form**
- Volunteer signup and contact section
- Dynamic statistics counter for meals served and volunteers onboarded
- Minimalistic, mobile-friendly design

---

## 🎨 Tech Stack

- **HTML5**
- **CSS**
- **Vanilla JavaScript (Pure JS)**
